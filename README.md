# TaskbarVolume

一个轻量的 Windows 任务栏音量工具：把鼠标放在任务栏上，滚动滚轮即可调整当前默认输出设备的音量。

使用原生 C++ 和 Win32 编写，无第三方库。程序通过 Windows 消息和设备通知工作，不使用后台轮询。

## 功能

- 在主屏或副屏任务栏上滚动，调整默认输出设备的主音量。
- 每一格滚轮增减 2 个百分点，音量对齐到偶数，范围为 0～100。
- 累计高精度滚轮的细小滚动量，达到一格后再调整。
- 音量降到 0 时静音；向上滚动时取消静音。
- 可选数字浮窗，显示在鼠标所在屏幕工作区的右下角。
- 浮窗不抢焦点，停止滚动约 900 毫秒后自动隐藏。
- 托盘设置支持开机启动和关闭浮窗。
- 单实例运行，重复打开不会启动多个副本。
- 默认输出设备变化时重新连接；Explorer 重建任务栏后恢复托盘图标。

## 使用

1. 获取或自行编译 `TaskbarVolume.exe`，放在准备长期保存的文件夹中。
2. 双击运行，程序在系统托盘中显示图标，没有常驻主界面。
3. 将鼠标移到 Windows 任务栏上，再滚动鼠标滚轮。
4. 点击托盘图标打开设置；右键图标可选择 **Settings...** 或 **Exit**。

程序只拦截任务栏区域的垂直滚轮事件。其他窗口内的滚动保持正常。

设置界面目前使用英文：

| 设置 | 含义 |
| --- | --- |
| Start with Windows | 当前用户登录 Windows 时自动运行 |
| Show volume overlay | 显示音量数字浮窗 |

启用开机启动后，请保持 EXE 路径不变。如果移动程序，需在新位置重新设置开机启动。

## 系统要求

- Windows 10 / 11 桌面环境，当前提供 x64 构建。
- 使用 Windows 标准任务栏。
- 调整音量时需要可用的音频输出设备。

鼠标位置使用 `GetCursorPos()`，与任务栏窗口判断使用同一坐标体系。当前 150% 显示缩放下已验证任务栏坐标判断。

自定义任务栏、第三方 Shell 或任务栏修改工具的兼容性未全面测试。

## 编译

需要 Visual Studio 2022 或 Build Tools，并安装 **使用 C++ 的桌面开发**工作负载及 Windows SDK。

打开 **x64 Native Tools Command Prompt for VS 2022**，进入项目目录后执行：

```bat
build.bat
```

输出文件为项目根目录的 `TaskbarVolume.exe`，中间文件保存在 `.build/`。

编译前请通过托盘菜单退出正在运行的程序，否则 Windows 会阻止覆盖 EXE。程序不依赖外部图标文件，托盘图标从 Windows 的 `mmsys.cpl` 获取。

## 运行逻辑

```text
启动
  → 检查单实例、读取设置
  → 创建隐藏消息窗口和浮窗
  → 连接默认音频设备、注册设备通知
  → 添加托盘图标、安装鼠标钩子
  → 等待 Windows 消息

任务栏上的滚轮事件
  → GetCursorPos 获取位置并判断任务栏
  → 累计滚动量并投递音量消息
  → 消息处理阶段读取并设置音量
  → 按设置显示浮窗，900 ms 无活动后隐藏

退出
  → 卸载钩子、移除托盘图标
  → 释放音频接口、窗口和绘图资源
```

鼠标钩子负责判断和投递消息，音频操作由主消息循环处理。应用不创建工作线程；Windows 音频通知可能从系统线程到达，回调仅向主窗口投递消息。

## 项目结构

| 文件 | 职责 |
| --- | --- |
| `main.cpp` / `app.h` | 启动、单实例、鼠标钩子和消息调度 |

| `tests/` | 集成测试和完整程序启动测试，不编入正式程序 |
| `TESTING.md` | 当前版本的验证记录和测试范围 |

## 测试

在同一个开发者命令提示符中执行：

```bat
test.bat
```

集成测试需要可用的默认音频输出设备和可见的任务栏。测试会短暂调整系统音量、显示浮窗及设置窗口，并恢复原音量和静音状态，不修改开机启动设置。

当前集成测试包含 42 项检查，覆盖滚动量累计、消息处理、音量边界、静音、设备通知处理、托盘恢复、浮窗计时及资源释放。连续重绘 300 次后 GDI 对象数量保持稳定。

完整程序启动测试：

```bat
smoke-test.bat
```

该测试会退出当前正在运行的 TaskbarVolume，验证启动、单实例、空闲 CPU 采样和正常退出；结束后需要自行重新运行程序。

设备切换与任务栏重建测试通过模拟通知完成。真实设备拔插、实际重启 Explorer、多屏组合和长期资源监测尚未全面覆盖。测试结果不代表所有 Windows 环境都已验证，详见 [TESTING.md](TESTING.md)。

## 设置保存与移除

浮窗设置保存在当前用户注册表的 `HKEY_CURRENT_USER\Software\TaskbarVolume` 中。

开机启动使用 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `TaskbarVolume` 项，不需要修改系统级配置。

移除程序时，先取消 **Start with Windows**，通过托盘菜单退出，再删除程序文件即可。保留的浮窗偏好设置不会让程序继续运行。

## 常见问题

**滚轮没有反应**

- 确认程序仍在运行，托盘图标可能被收在隐藏图标区域。
- 确认鼠标位于任务栏，而不是普通应用窗口。
- 确认 Windows 当前有可用的默认音频输出设备。
- 同时使用其他任务栏滚轮工具时，可能出现事件拦截冲突。

**没有显示浮窗**

检查设置中的 **Show volume overlay** 是否开启。音频操作失败时，程序不会显示未经成功设置的音量值。

**移动程序后开机启动失效**

在新位置运行 EXE，重新设置 **Start with Windows**，更新保存的程序路径。
